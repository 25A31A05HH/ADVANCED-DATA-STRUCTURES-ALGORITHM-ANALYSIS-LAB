# Algorithms and Data Structures (ADS) Lab

This repository contains my C++ solutions and implementations for the Algorithms and Data Structures Lab course.

## 🚀 Getting Started

### Prerequisites
To compile and run these programs, you need a C++ compiler installed on your system:
* **GCC/G++** (Linux/MinGW for Windows)
* **Clang** (macOS)

### Compilation and Execution
To run any specific C++ file, navigate to its directory and use the terminal:

```bash
# Compile the program
g++ -O3 main.cpp -o program

# Run the executable
./program
```

## 📁 Repository Structure

* `01_Arrays_and_Vectors/` — Dynamic arrays, matrix operations, sliding window.
* `02_Linked_Lists/` — Singly, doubly, and circular linked lists.
* `03_Stacks_and_Queues/` — Array and list-based implementations, expression evaluation.
* `04_Trees/` — Binary Trees, Binary Search Trees (BST), and AVL Trees.
* `05_Graphs/` — Adjacency matrices/lists, BFS, DFS, and shortest path algorithms.
* `06_Sorting_and_Searching/` — QuickSort, MergeSort, Binary Search, and HeapSort.
